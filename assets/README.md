## Как подключить фото вместо заглушки

Сейчас на месте оставшихся фото — цветные плейсхолдеры с подписью файла. Чтобы поставить реальное фото, найдите в `index.html` нужный блок и замените:

```html
<figure class="ph ph--rev"><span class="ph__label">assets/review-1.jpg</span></figure>
```

на:

```html
<figure class="ph ph--rev"><img src="assets/review-1.jpg" alt="Отзыв ученицы"></figure>
```

Класс `ph--*` оставляем — он задаёт пропорции. Как только внутри `.ph` появляется `<img>`,
декоративная штриховка и подпись с именем файла прячутся сами (см. `.ph:has(img)` в `styles.css`) —
дополнительно ничего дописывать не нужно.

## Подготовка файлов

- JPG, качество 80–85
- Максимум 1920px по длинной стороне (для `hero-portrait.jpg` можно 2400px)
- Вес одного файла — до 400 КБ, иначе страница будет грузиться долго на мобильном интернете
- Оригиналы без сжатия хранить отдельно, не в этой папке
