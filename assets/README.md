## Как подключить фото вместо заглушки

Сейчас на местах фото стоят цветные плейсхолдеры с подписью файла. Чтобы поставить реальное фото, найдите в `index.html` нужный блок и замените:

```html
<figure class="ph ph--portrait"><span class="ph__label">assets/hero-portrait.jpg</span></figure>
```

на:

```html
<figure class="ph ph--portrait"><img src="assets/hero-portrait.jpg" alt="Лиана Шанибова, косметолог"></figure>
```

Класс `ph--*` оставляем — он задаёт пропорции. Добавьте в `styles.css` одну строку, чтобы картинка заполняла рамку:

```css
.ph img{ width:100%; height:100%; object-fit:cover; }
```

## Подготовка файлов

- JPG, качество 80–85
- Максимум 1920px по длинной стороне (для `hero-portrait.jpg` можно 2400px)
- Вес одного файла — до 400 КБ, иначе страница будет грузиться долго на мобильном интернете
- Оригиналы без сжатия хранить отдельно, не в этой папке
