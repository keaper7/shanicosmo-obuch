# Лендинг курса «Косметология с 0» — Лиана Шанибова

## Что в папке

```
docs/
  01-структура-лендинга.md   — поблочный wireframe, логика каждого блока
  02-тексты-лендинга.md      — готовые продающие тексты всех блоков
  03-тз-фотосессия.md        — чек-лист съёмки: 18 кадров + 6 опциональных + 4 видео
  04-лид-магниты.md          — 3 варианта лид-магнита с текстами попапов

index.html                   — страница, все тексты внутри
styles.css                   — стили, палитра в CSS-переменных
script.js                    — аккордеоны, дата потока, sticky-CTA
assets/README.md             — куда класть фото и как их подключить
```

## Как посмотреть

```bash
python3 -m http.server 4321
```

Открыть `http://127.0.0.1:4321`. Просто дважды кликнуть по `index.html` тоже сработает.

## Что учтено

Смыслы — из стратегии продвижения: нишевание на медсестёр и студентов-медиков, приём
«контраст сейчас → после», роль проводника вместо продавца.

**Тарифы** — по актуальным данным: групповой 49 900 ₽ (было 100 000 ₽), индивидуальный 77 000 ₽.
Старый скрин с «Премиум 70 000» не используется.

## Оформление

Направление — редакционно-клиническая эстетика: тёплая бумага, глубокие чернила,
один бронзовый акцент, тонкие линии, номера разделов на полях.

| | |
|---|---|
| Заголовки, цифры | **Cormorant Garamond** 300–500, курсив для акцентов |
| Текст и интерфейс | **Golos Text** 400–600 |
| Бумага | `#FBF6EE`, секции с подложкой `#F4ECE0` |
| Чернила | `#1C2135` |
| Бронза (акцент) | `#9C5F2C` |
| Пудра / золото | `#E7C3D5` / `#E3BE6E` |
| Тёмные секции | `#171C2E` / `#10141F` |

Это отход от брендбука стратегии (там были Montserrat + Manrope и палитра
`#FEFBF5 / #EEC5DE / #FFE098 / #A86437 / #6D4437 / #1F273F`) — сделан осознанно,
чтобы страница читалась как премиальная клиника, а не как типовой инфокурс.
Логика палитры сохранена: чистая база + один цвет вдохновения + акцент успеха.
Если нужно вернуться к брендбуку — правятся только переменные в начале `styles.css`.

**Важно про цифры:** Cormorant по умолчанию рисует минускульные цифры, из-за чего
«31» читается как «3I», а «3 модели» — как «з модели». В `styles.css` есть блок,
принудительно включающий маюскульные цифры. Если добавляете новый заголовок
с числом — впишите его селектор в этот список.

## Надёжность

Анимация появления блоков — украшение, а не условие видимости:

- контент виден по умолчанию, скрывается только если JS отработал (класс `js` на `<html>`);
- всё, что попало в экран при загрузке, показывается сразу;
- страховочный таймер раскрывает страницу через 2 секунды в любом случае.

Так страница не может оказаться пустой из-за блокировщика, ошибки скрипта или старого браузера.
