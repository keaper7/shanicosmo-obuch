## Как посмотреть

```bash
python3 -m http.server 4321
```

Открыть `http://127.0.0.1:4321`. Просто дважды кликнуть по `index.html` тоже сработает.

## Оформление

Направление — тёплая бумага как основа, шоколадно-коричневый и бордовый как акценты.
Шоколадный подобран в цвет рабочей формы Лианы с реальной фотосъёмки — сайт и
фото читаются одним брендом. Бежевая база держит бо́льшую часть страницы, два
шоколадных блока (шапка, финал + футер) держат бренд-цвет, бордовый — тонкая
деталь (числа, чек-марки, бейдж лучшего тарифа, цитата), не большие заливки.

| | |
|---|---|
| Заголовки, цифры | **Cormorant Garamond** 300–500, курсив для акцентов |
| Текст и интерфейс | **Golos Text** 400–600 |
| Бумага (фон страницы) | `#FBF6EC`, секции с подложкой `#F2E6D2` |
| Карточки | `#FFFFFF`, тёплая подложка внутри `#E9D4C3` |
| Чернила на бумаге | `#2A1810` |
| Шоколадные блоки | шапка / финал / футер — `#2E1B12` / `#20120B` |
| Бордовый (тонкий акцент) | `#4E0000` |

Заказчик задал тройку `#13273F / #4E0000 / #E9D4C3` (тёмно-синий / бордовый /
бежевый) и бежевый доминантой — осознанно: бордовый на больших поверхностях
(кнопки, целые секции) в теме косметологии считывается как ассоциация с кровью,
поэтому он используется только в мелких деталях, где такого прочтения не
возникает. Когда пришла реальная фотосъёмка — рабочая форма оказалась
шоколадно-коричневой, без единого синего пятна — тёмно-синий заменили на
шоколадный в тон форме, чтобы сайт и фото не спорили друг с другом; логика
«бежевая база + один тёмный + бордовый штрихом» осталась той же. Это отход от
брендбука стратегии (там были Montserrat + Manrope и палитра
`#FEFBF5 / #EEC5DE / #FFE098 / #A86437 / #6D4437 / #1F273F`) — сделан осознанно
по цветам, которые выбрал заказчик, и уточнён по реальным фото.

**Как устроена перекраска.** В `:root` лежат «дневные» значения переменных —
бумага как основа. Три тёмных блока (`.hdr, .final, .ftr`) переопределяют
внутри себя `--ink*`, `--hair*` и акцентные `--bronze/--cocoa` на светлые
(бежевый вместо бордового — на тёмном бордовый тоже теряет контраст), поэтому
их текст и мелкие акценты становятся «ночными» сами, без правки каждого правила.
Чтобы сменить палитру целиком, достаточно `:root` и этого блока в начале `styles.css`.

**Важно про цифры:** Cormorant по умолчанию рисует минускульные цифры, из-за чего
«31» читается как «3I», а «3 модели» — как «з модели». В `styles.css` есть блок,
принудительно включающий маюскульные цифры. Если добавляете новый заголовок
с числом — впишите его селектор в этот список.

## Надёжность

Анимация появления блоков — украшение, а не условие видимости:

- контент виден по умолчанию, скрывается только если JS отработал (класс `js` на `<html>`);
- всё, что попало в экран при загрузке, показывается сразу;
- страховочный таймер раскрывает страницу через 2 секунды в любом случае.

Так страница не может оказаться пустой из-за блокировщика, ошибки скрипта или старого браузера.
